# Fridge Management UI Prototype

Interactive Figma prototype for a fridge-management application.

## Project Overview

Designed a multi-screen user interface for managing shared fridge accounts, inventory, and user actions. The prototype includes clickable navigation between screens to simulate a functional application workflow.

## Features

- Login and account creation
- Account and user management
- Fridge creation and management
- Inventory/list views
- Edit and update workflows
- Confirmation and error states
- Interactive page navigation through Figma prototyping

## Tools

- Figma
- UI/UX Design
- Wireframing
- Interactive Prototyping
- User Flow Design

Designed the interface, screen layouts, user flows, and interactive prototype.
